# S03: Dashboard UI and error handling

**Milestone:** M001
**Slice:** S03

**Goal:** Add an Angular route where a user enters an NSE/BSE ticker and sees all 8 fundamental metrics rendered live from the Express proxy, with distinct UI states for loading, invalid ticker, upstream failure, and partial (per-metric N/A) data.
**Demo:** A new Angular route lets a user type a ticker and see all 8 metrics rendered live from the proxy, with working error states for invalid ticker, upstream failure, and partial data.

## Must-Haves

- User can navigate to /fundamentals, enter a ticker, and see a metrics grid or an appropriate error state; playwright smoke test passes against the built app.

## Proof Level

- This slice proves: integration

## Integration Closure

Wires new StockService + FundamentalsComponent into AppModule/routing, calling the already-complete proxy endpoint GET /api/stock/:ticker (S01/S02). After this, the milestone's end-to-end user loop (ticker in, 8 metrics out) is fully wired.

## Verification

- UI surfaces distinct error states (not-found/upstream/network) with retry; per-metric N/A rendering for partial data; console logging for HTTP errors in StockService.
