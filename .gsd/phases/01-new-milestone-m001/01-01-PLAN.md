# S01: Proxy foundation and core valuation metrics

**Milestone:** M001
**Slice:** S01

**Goal:** Create a standalone Node/Express TypeScript proxy server that exposes GET /api/stock/:ticker, fetches live data from Yahoo Finance via yahoo-finance2's quote() call, maps it to {marketCap, currentPrice, week52High, week52Low, peRatio, bookValue, dividendYield}, caches responses in-memory per ticker for ~5 minutes, and returns distinguishable 404 (invalid ticker) vs 502 (upstream failure) error responses.
**Demo:** GET /api/stock/RELIANCE.NS on a live local Node/Express proxy returns Market Cap, Current Price, 52-Week High/Low, Stock P/E, Book Value, and Dividend Yield as JSON, fetched live from Yahoo Finance via the yahoo-finance2 package.

## Must-Haves

- GET /api/stock/RELIANCE.NS on the running local proxy returns 200 JSON with all 6 fields as non-null numbers; GET /api/stock/NOTAREALTICKERXYZ returns 404; a repeat call to the same valid ticker within 5 minutes is served from the in-memory cache (verified via debug log or timing)

## Proof Level

- This slice proves: runtime-executable

## Integration Closure

Establishes server/ as a standalone Express+TS project alongside the existing Angular app; exposes the JSON contract and error shapes (404/502) that S02 extends with roce/roe and S03 consumes from the Angular UI.
